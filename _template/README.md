# 报告模板

`report.html` 是全站统一骨架。新增一期报告的步骤：

1. 复制到 `<专题>/<YYYY-MM-DD>/index.html`
2. 替换 `{{占位符}}`
3. 保留 `<head>`、面包屑 `.crumb`、页脚 `.foot` 三段结构 —— 这三段决定全站导航一致性
4. 正文按所属专题 README 的「必含模块」写
5. 回到该专题 `README.md` 的版本表加一行，并在专题 `index.html` 加一张卡片

## 样式

- 所有新报告引用 `assets/report.css`（模板里写的是 `../../assets/report.css`）
- **改版式只改 `assets/report.css`**，历史报告如果是自包含样式则不受影响
- 需要特殊图表时可以内联 `<style>`，但要在该期页脚注明「本期内联样式，未跟随全站改版」

## 命名

| 情况 | 目录 |
|---|---|
| 正常一期 | `2026-11-13/` |
| 同日重大修订 | `2026-11-13-r2/` |
| 同源内容订正 | 直接覆盖原目录，页脚写「修订」 |

## 配色约定（中式习惯）

- 涨：红 `--rise`
- 跌：绿 `--fall`
- 看空标签 `.tag.bear` 用绿，看多 `.tag.bull` 用红
