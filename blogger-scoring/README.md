## 打分的四条硬口径

1. **超额胜率**：命中率 − 同日同向「无脑喊」基准。2026 年随机喊涨/跌各有约 2/3 命中，不扣基准等于人人都是高手。
2. **周期分层**：只用 `horizon = months / quarters` 的预测评「大周期」，用「60/90 天后收盘方向 ≥10%」判定，而不是「窗口内曾经触及」。
3. **顶底提前预判**：必须在拐点前 7–90 天给出方向，按提前天数加权；**拐点当天及之后喊底 = 事后确认，不计分**。
4. **历史一致性（2026-11-13 新增）**：`trendFollow ≥ 0.72` 且 `n ≥ 8` 的账号，评级封顶 B —— 顺势者在单边行情里必然对，那不是能力。

附加纪律：

- 样本收缩 `n/(n+6)`，可结算 < 3 条不参与排名；
- **博主的自我叙述不能当证据**（「我是一直看空」必须回台账核对）；
- 同一人同期给出方向相反的硬目标，标注但单独判。

## 观点承诺台账

每期事件后建一份可机械判定的台账（`calls_ledger.json`），字段：原文 quote / 派系 / 类型 / 目标位 / 起算日 / 结算日 / 判定结果。

判定类型写死，不临场解释：

| 类型 | 判据 |
|---|---|
| `down` | 窗口内最低价 ≤ 目标 |
| `up` | 窗口内最高价 ≥ 目标 |
| `bottom` / `hold` | 跌破 目标×0.97 即判错；未破则到结算日判对 |
| `reject` | 连续 2 日收盘站上该位 → 判错 |

**拉黑规则**：

- 极端看空（≤60k）到期未跌到、且已站上 70k → 拉黑
- 看底派被跌破 level×0.97 → 降级；累计 2 次 → 拉黑
- 过期未兑现的 `up` 目标（如 105k）→ 按同一规则处理

## 更新机制（2026-11-13 定稿）：日报不进 02，02 只出「周期快照」

**结论：每日抓取的帖子不能直接更新 02。** 三个原因，都是硬的：

1. **周期不匹配**：02 评的是「大周期判断力」，判据是 60/90 天后的收盘方向；今天的帖至少要 60 天后才可结算，当天就打分等于用未出生的数据下结论。
2. **样本不够**：实测（2026-11-13 快照）96 个账号里，大周期可结算 ≥8 条的只有 **1 个**，中位数 **0 条**，另有 **75 条待结算**。用 1–2 条预测排名，排的是运气。
3. **横向不可比**：同一天不同博主给的周期不同（有人喊下周、有人喊明年），混在一张表里排名没有意义。

### 三种产出节奏（各管一段，互不替代）

| 节奏 | 产出 | 数据基础 | 是否排名 |
|---|---|---|---|
| **每日** | 只更新 03（观点）与 01（行情）；台账追加新观点、结算到期项 | 当日抓取 | 不排名，只有「这次谁对」 |
| **每月末**（或重大事件后） | **02 周期快照**（本专题唯一排名页） | 已结算的大周期预测 | 达标才排名，未达标进观察榜 / 样本不足 |
| **每年** | 02 年度全量重算（可扩语料重抽） | 全年预测 + 全年日线 | 全量排名 + 分层命中率 |

### 数据流

```
每日抓取 ──► 观点抽取 ──► state/calls_ledger.json（append-only，含起算日/结算日/判据）
                              │
                              ├─ 到期即结算（verify_calls.js，判据写死）
                              ▼
                     output/scorecard/scorecard_<asof>.json + .md
                              │
                              ▼
                     02 月季快照页（blogger-scoring/<YYYY-MM-DD>/）
```

- 台账只追加不改写；判定结果一经产出不改（要推翻必须新开一条 `-r2`）
- 快照必须写死 `asof`（只用该日之前的行情），禁止「拿未来行情回填历史预测」

### 快照打分口径（`score_periodic.js`）

| 项 | 权重 | 说明 |
|---|---|---|
| 大周期超额 | **60** | `months` / `quarters` 可结算预测的命中率 − 同日 ±45 天同向基准；终点方向 ≥10% 才算兑现 |
| 顶底提前预判 | 20 | 拐点前 7–90 天给出方向 + 点位（±3% 内满分、±8% 内 0.7），机会归一避免「只覆盖 1 个节点」封神 |
| 短期命中 | 8（上限 5 分） | `weeks` 口径，仅作辅助——按用户口径短期准确率弱化 |
| 口径不稳定 | −5 | 分季度一致性差（季度间命中率差 >34pt）扣分 |

**入榜门槛**：`months + quarters` 可结算 **≥8 条** 且跨度 **≥60 天**。
`3–7 条` → 进**观察榜**（标 `·初`，不作结论）；`<3 条` → 「样本不足」，只列条数不排名。

## 每期必含模块

1. 摘要 KPI（账号数 / 样本数 / 这次判对判错条数）
2. 判定结果表（已判错 / 已命中 / 待定 / 观察）
3. 建议降级·拉黑名单（**必须引用原话 + 判定数据**）
4. 下次结算时间表
5. 口径说明与局限
