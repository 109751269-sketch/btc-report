## 每期必含模块

1. **摘要 KPI**（4 个）：现价 / 区间高低 / 涨跌幅 / 一个规模指标（爆仓额、ETF 流向等）。
2. **行情时间线**：日期 · 收盘 · 当日涨跌 · 事件。
3. **驱动因素**：分条列，每条必须带可核对的数字（如「CPI 环比 0.4% vs 预期 0.3%」）。
4. **关键价位**：支撑 / 阻力 / 心理关口，标注来源（技术位、均线、链上成本）。
5. **数据来源与口径**：交易所、时间窗、是否为盘中快照。

## 更新流程

1. 复制 `_template/report.html` → `<YYYY-MM-DD>/index.html`
2. 只替换正文与 KPI；`<head>`、面包屑、页脚结构保持不变
3. 页面引用 `../../assets/report.css`（不要内联新样式，除非该期需要特殊图表）
4. 在本 README 版本表加一行，并在 `macro-events/index.html` 加一张卡片

## 命名

- 正常一期：`2026-11-13/`
- 同日重大修订：`2026-11-13-r2/`
- 不覆盖历史目录

## 版式演进

- **全站统一深色**（`--bg:#080a0f`，金色 `#f0b429` 强调），与 2026-11-08 / 11-11 期一致。
- 新报告引用 `assets/report.css`；**历史报告已统一转深色，只换样式、内容未改**。
- 改版式：只改 `assets/report.css`（历史自包含样式的页面不受影响）。
- 需要整体换版：逐期新建 `YYYY-MM-DD-r2/` 目录，不原地覆盖。
