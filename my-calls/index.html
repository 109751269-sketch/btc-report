三、依据审查与统计

我的判断依据会先做回测检验，再写进台账。检验不过的依据照样留档，标「无效」——这样事后能分清方向对和依据对。

怎么读下面这张表
  • 样本 N 次：历史上这个信号一共触发过多少次。样本越少，结论越不可靠。
  • N 日上涨 x%：信号出现后第 N 天，BTC 收盘价高于信号当日收盘价的比例。只要求「涨了」，涨多少都算。
  • N 日触及 y%：信号出现后 N 天内，BTC 任意一天的最高价曾涨到目标幅度（本次为 +11.85%，即 67,057 → 75,000）的比例。这个要求比「上涨」高得多。
  • 基准 z%：不看信号、随便挑一天进场的同口径命中率。2024-2026 年市场整体偏涨，所以基准本身就有 51%~54%。
  • 超额 = 信号 − 基准。只有超额为正，信号才有价值；等于基准说明这个依据等于没看。

四、方法与局限

  • 价格来源：Binance BTCUSDT 日线（UTC 00:00 收）。不同交易所低点可能差几十美元，以本条为准。
  • 窗口从记录日次日算起，不拿当天已发生的行情倒推，避免「事后诸葛」。
  • 只判方向是否触及目标，不判路径、不判中间波动。触及即命中，到期未触及即未中。
  • 已知偏差：单根日线内「先破后达」无法区分；样本不足时胜率不可外推。
  • 本页不记录仓位、资金规模与盈亏，不构成投资建议。
